개인정보 운영 상태
- 공개 양식에는 개인정보 수집·이용 동의만 적용
- 제3자 제공 및 국외 이전에 관한 별도 동의 항목은 운영하지 않음
- 개인정보처리방침에는 제3자 상시·정기 제공이 없음을 명시
- Tally·Notion·Google은 실제 사용하는 외부 업무 도구로 안내
- 고유식별정보 또는 민감정보 처리 시 법령상 근거 또는 별도 동의 필요
- HiKorea 비밀번호는 웹 양식·이메일에서 받지 않고 별도 절차로 처리

배포 방법
1. 이 폴더의 내용 전체를 정적 웹호스팅의 공개 루트에 업로드합니다.
2. 기본 문서가 index.html로 열리는지 확인합니다.
3. HTTPS와 사용자 도메인을 연결합니다.
4. 공개 URL에서 한국어·영문 홈페이지, 개인정보처리방침, 외부 링크를 최종 확인합니다.

참고
- GitHub Pages 기본 도메인을 기준으로 canonical URL, 언어 대체 URL, robots.txt 및 sitemap.xml을 구성했습니다.
- 추후 사용자 도메인을 연결하면 위 주소들을 새 도메인 기준으로 변경해야 합니다.
